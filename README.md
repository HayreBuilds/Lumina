> **LUMINA** is a high-performance full-stack application leveraging the latest NVIDIA NIM APIs to solve complex domain-specific challenges with state-of-the-art AI.

---

## ✨ Key Features

- **🧠 Powered by NVIDIA NIM**: Seamless integration with specialized AI endpoints.
- **⚛️ Modern Tech Stack**: Built with React, Express, and TypeScript.
- **🛡️ Enterprise Ready**: Includes security middleware, PII detection, and rate limiting.
- **⚡ Real-time Processing**: Streaming support for LLM responses and real-time data visualization.
- **🎨 Premium UI**: Beautiful, responsive interface designed for power users.

---

## 🚀 Quick Start

### 1. Configure Environment
Create a `.env` file in the root directory:
```env
NVIDIA_API_KEY=nvapi-your-key-here
PORT=3001
```

### 2. Install & Run
```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

---

## 🛠️ Tech Stack

- **Frontend**: React 18, Tailwind CSS, Lucide Icons, Axios
- **Backend**: Node.js, Express, TypeScript, Helmet, Morgan
- **AI Models**: NVIDIA NIM (Nemotron, LLaMA-Vision, ESMFold, etc.)
